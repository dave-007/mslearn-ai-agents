USAGE INSTRUCTIONS
════════════════════════════════════════════════════════════════════════════════
1. Navigate to the Solution directory:
   cd /path/to/Labfiles/06-build-remote-agents-with-a2a/Solution

2. Configure .env file:
   - Set PROJECT_ENDPOINT to your Azure AI Foundry endpoint
   - Ensure MODEL_DEPLOYMENT_NAME is set to "gpt-4o"

3. Install dependencies:
   pip install -r requirements.txt azure-ai-projects azure-ai-agents a2a-sdk

4. Sign into Azure:
   az login

5. Run the solution:
   python run_all.py

6. Interact with the agent:
   - Enter prompts like: "Create a title and outline for React programming"
   - Type 'quit' to exit
